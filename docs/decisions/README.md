# Designbeslut

Detta är en logg över större designbeslut i projektet. Varje fil är ett enskilt beslut.

Format för beslutsfiler:
- Filnamn: `YYYY-MM-DD-kort-beskrivning.md`
- Innehåll: Kontext, beslut, motivering, alternativ som övervägdes

Detta är inspirerat av ADR (Architecture Decision Records).
