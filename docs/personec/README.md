# Personec-observationer

Denna mapp innehåller insikter från Personec-systemet som Töreboda hemvård använder idag.

## Viktigt om personuppgifter

🔒 **GDPR-respekt:** Innan skärmdumpar laddas upp ska kollegors namn maskeras. Använd t.ex.:
- macOS Preview: ritverktyg för att sudda
- MS Paint / Skitch: textöverlägg
- Eller mobilen: markera och censurera

Ersätt namn med "Person A", "Person B" etc. Behåll struktur och datatyper.

## Vad vi vill veta från Personec

Inte själva datan, utan **strukturen**:

1. **Hur fält och kategorier är uppbyggda**
   - Vad finns för olika passtyper i Personec?
   - Vilka koder används?
   - Hur länkas pass till personer?

2. **Hur saldon visas och beräknas**
   - Vilka saldotyper finns?
   - Hur räknas timmar fram?
   - Hur visas över/under-tid?

3. **Hur helger och röda dagar markeras**
   - Vilken kodning används?
   - Hur skiljs storhelg från vanlig helg?

4. **Hur byten och justeringar görs**
   - Vilka steg behövs för att byta ett pass?
   - Var registreras anteckningar?

5. **Vad som inte syns i Personec**
   - Vad gör samordnaren utanför systemet?
   - Vilka uppgifter hanteras manuellt?

## Filstruktur

Lägg skärmdumpar med beskrivande namn:
- `01-saldoöversikt.png`
- `02-månadsschema-tomt.png`
- `03-passtyper-konfiguration.png`
- `04-helgmarkering.png`
- etc.

Komplettera gärna med en kort text i `observations.md` för varje skärmdump.
